# Labeling Guidelines

## Normal
Regular conversation without manipulation.

Examples:
- How are you?
- Let's meet tomorrow.

## Gaslighting
Making someone doubt their memory, perception, or reality.

Examples:
- That never happened.
- You're imagining things.

## Guilt Tripping
Using guilt to influence behavior.

Examples:
- After all I've done for you.
- I sacrificed everything for you.

## Emotional Blackmail
Using threats, fear, or emotional pressure.

Examples:
- If you leave me, I'll never forgive you.
- Do this or you'll regret it.

## Love Bombing
Excessive affection used to create dependency.

Examples:
- You're perfect.
- Nobody understands me like you do.
